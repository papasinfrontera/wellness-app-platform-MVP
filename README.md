# WELLNESS APP — MVP

Nueva aplicación Next.js + TypeScript, separada del demo publicado.

## Objetivo

Crear la interfaz para análisis longitudinales, importaciones de PDF, datos WHOOP, hábitos y WELLNESS Intelligence.

## Preservación

El demo aprobado no se modifica: https://wellness-app-demo-sprint1-papasinfronteras-projects.vercel.app

- Next.js + React + TypeScript
- API segura y autenticación Supabase
- Integraciones con el backend y base científica independientes
- Desarrollo por ramas y revisión antes de producción
